## **1. 2D Matrix Multiply Using Shared Memory**
This example introduces two-dimensional threadblock/grid shape. Study the code, `matrix_mul.cu` and see how the 2D indexing is implemented. This naive version has too many global memory access. Now implement a shared memory version (loading tiles of A, B into shared memory in parallel) to the 2D matrix multiply given above to improve performance. Study the runtime of both codes and see whether you notice an improvement when using shared memory. 

## **2. 2D Heat Transfer Simulation with CUDA**
This exercise illustrates the usage of texture memory, to take advantage of on-chip caching. The specific example is to simulate the 2D heat transfer, using a finite-difference method. An example of using a simple finite-difference approximation on a one-dimensional data set is given to illustrate the GPU implementation, see `fd.cu`. Texture memory is a way to store data on GPU to provide a boost to performance, especially where there exists spatial coherence in the data access patterns. The texture memory version of the finite-difference program is also give, see `fd_texture.cu`. Finally, the texture memory implementation of the 2D heat transfer is given in `heat.cu`. The example shows the choice of one-dimensional block/grid shape. Your assignment is to implement a two-dimensional texture and compare the performance with when using one-dimensional textures. Note that you will also need two header files `book.h` and `cpu_anim.h` put in the same directory as your code.
