In this chapter, we will give a brief overview of OpenCL.
The fundamental programming model of OpenCL is similar to
CUDA; we will point out this one-to-one correspondence for
main features. With students' background of CUDA, covered in 
previous chapter, you will learn writing OpenCL programs 
with the material presented in this chapter. We will then
show mapping of the OpenCL features to their CUDA equivalents.
