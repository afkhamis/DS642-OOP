# Final Project

Final project should be about understanding performance and the majority of the efforts must be about parallelism; this can involve an existing code, or implementting a method from a research paper. 

You must submit a brief project proposal. Consider including the following:

*  A description of the problem in terms of its scietific relevance.

*  Are benchmark results available and if so, how do they compare with the simulations. 

*  Which parallel plateform is used or will be used, e.g. distributed/shared memory, GPU, ....

*  Have you invetigsted how well the application perform compared to the peak performance of the cluser computer you will be using.

*  How does the application "scale" with the number of processors. 
    
*  Can you identify the bottlenecks limiting the performance of the application.

  

Below is a short list of possible projects:

*Parallelizing a Particle Simulation (Particles move in space according external, nearby, and far field forces)*

*Finite Element/Finite Difference Domain Decomposition (Parallelization of a Finite Element/Finite Difference Solver for the Heat Equation)*

*Parallelized Singular Value Decomposition*

*Monte Carlo Simulation*

*Pseudospectral Methods (using FFTW)*

*Adaptive Poisson Solver and Graph Partitioning for Load Balancing*

*Parallelized Stochastic Gradient Descent*

*Fast Parallel Iterative Matrix Diagonalization*

*Parallel Preconditioned Conjugate Gradient*

*Parallel Solvers for Tridiagonal Linear Systems*
